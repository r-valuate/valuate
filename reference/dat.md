# Conjunto de datos \`datos\`

Este dataset contiene valores de utilidad territorial (\`vut\`) y su
ubicación geográfica.

## Usage

``` r
dat
```

## Format

Un data frame con las siguientes columnas:

- vut:

  Valor de utilidad territorial del punto.

- geometry:

  Coordenadas geográficas del punto.

## Source

Datos geoespaciales procesados.
